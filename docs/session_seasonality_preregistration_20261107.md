## 0. 为什么现在写，以及必须坦白的污染

2026-11-07 已生成 `reports/session_threshold_audit_20261107.md`：3 个交易日、
445 帧、49 个 5 分钟桶，其中早盘 `break_rate_proxy` 从 **0.0**（0925）升到
**0.2127**（0940）。**这些数字已经被看过。** 因此任何「早盘不一样」的念头都带有
事后挑窗的风险，不能假装是干净的先验假设。

处理办法不是不研究，而是把污染隔离：

| 类别 | 日期 | 用途 |
|---|---|---|
| **探索期（已污染）** | `20261104` / `20261105` / `20261106` | 只用于描述与提出假设，**永久排除**出确认性样本与样本外 |
| **确认性样本** | **2026-11-09 起**新采集的交易日 | 唯一可用于判定 H1 的数据 |
| **lockbox（样本外）** | 确认性样本按时间顺序的**最后 20%** | 在达到 60 日之前**不得读取其结果** |

金融时序的样本外切分按**时间先后**，不随机打散；最后 20-30% 留出比随机切更有意义
（方法校核：out-of-period testing）。**两窗不同即判不可辨，不许挑窗**（本台既有纪律）。

## 1. 单一主假设

- **H1（主，唯一确认性检验）**：在**未看过**的确认性样本上，早盘窗口
  `09:30-09:59` 的 `break_rate_proxy` 分布相对盘中基准窗口 `10:30-13:59`
  的差异，在开发期与 lockbox 中**同号且幅度稳定**。
- **H0**：差异不稳定——样本外符号翻转，或幅度相对开发期衰减 **> 50%**。
- 只立**一个**主假设。理由：每多一个检验就多一次撞上运气的机会；49 个桶逐个挑最优
  属于探索，不是确认（Bonferroni：N 个检验需 α/N，且结果只能记为探索）。

**机制上的预期**：日内 U 型主要是**日历时间聚合**的外观（近开盘/收盘过度聚合会高估，
trade-time 估计日内下降超 50%）。所以本研究的默认预期是 **H0 成立**；若 H1 通过，
也需要先排除聚合假象，而不是直接宣称「发现季节性」。

## 2. 数据口径

- 源：`pool_tape`，**单表内**按自身 `snapshot_ts` 分 5 分钟桶（D-12）。
  **禁止**拿 `snapshot_ts` 做 `rt_quote ↔ pool_tape` 跨表连接键（D-9）；跨表只用
  同源 `frame_id`。
- 指标：`break_rate_proxy` = 行级「炸板池行 /(涨停池行 + 炸板池行)」。它与日级
  `sentiment.break_rate_gate = 0.38` **口径不同，禁止机械比较**。
- 每桶同时报 `n_frames` 与 `n_rows`；`n_frames < 20` 的桶不参与判定；分组样本数
  门槛沿用 `configs/params.yaml:312` 的 `min_bucket_n = 30`。
- **OBI₅ = 1.0 是涨停封板时卖档为 0 的结构性结果**，不是买盘强度，不得作信号或排序。
- 冷存上线前（< 2026-11-07）的分区没有 `frame_id`，**永久不可回补**，不得用别的数据源假装补上。

## 3. 成功判据（四条必须同时满足）

1. 开发期与 lockbox 中，主窗口 vs 基准窗口的差异**同号**；
2. 样本外幅度相对开发期**衰减 ≤ 50%**（`max_out_of_sample_decay = 0.50`）；
3. 参与判定的每个桶 `n_frames ≥ 20`，且分桶样本数 ≥ 30；
4. 样本覆盖 **≥ 3 个 regime**（按 `configs/params.yaml:92-101` 分档）。

`alpha = 0.05` 仅作参考，**p 值不是效应稳定性**；负结果同样要写进台账并发布。

### 成功**不是**什么

- 不是更高的净值 / 更漂亮的资金曲线；
- 不是更小的 p 值；
- 不是「终于找到某个表现最好的分桶」——那是探索，不是确认。

沿用 D-8 / P3 的纪律：**不以净值曲线变好作为成功标准，本改造不产生 alpha。**
