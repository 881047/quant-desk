# LLM 思考协议（P6）

> 这份文件解决一个问题：**模型在系统里到底负责"想"什么。**
> 如果它只是从排好序的候选里挑一只，那它不是交易员，是一个带界面的下拉框。
> P4/P5 已经证明：靠规则枚举出来的短线手法全部失败。剩下能改进的只有一件事——
> 让模型提出规则没想到的机制，并且**用可打分的方式记录它想得对不对**。

---

## 0. 前提：赚钱的应该是模型，不是内核

这句话必须写在最前面，因为它决定了整个系统的形状：

- **内核不产生 alpha**。它做四件事：把数据变干净、把成交算准、把风险管住、把假设证伪。
  P4–P8 里它证伪了 9 个短线结构——这是它的正确用法，不是它的失败。
- **alpha 只能来自对世界的判断**：哪条信息还没被定价、哪种资金流是被迫的、哪个叙事刚开始。
  这些是 LLM 的活，规则写不出来；写出来就已经被套利了。
- **所以内核的 KPI 是"不亏 + 不骗自己"，模型的 KPI 是"跑赢等权市场"**。
  两者都不许越界：内核不许替模型选股，模型不许改风控和账本。

判断模型有没有做到，只有一个指标：**已平仓决策相对等权市场的超额，以及它的置信区间**。
NAV 不算——¥5,000 的账户，一个仓位就能把曲线拉成任何形状。

## 1. 分工

| 角色 | 负责 | 不负责 |
|---|---|---|
| **模型** | 观察异常、提出机制、写可证伪假设、给概率、盘后归因 | 算价格、算仓位、算盈亏、改风控、改判决 |
| **Python** | 数据、撮合、成本、风控、统计裁判、打分 | 解释为什么、判断该不该 |
| **人** | 激活 playbook、放行资金、决定方向 | 逐笔决策 |

模型的输出不是"买哪只"，而是**"我认为世界如何运作，以及如果错了会在哪里露馅"**。

## 2. 一个完整回合

```
quant_discover                    ① 看原始事实（宽度/涨停结构/行业分化/跳空行为/核心 regime）
      ↓
（模型自己的推理：哪条事实反常？机制是什么？）
      ↓
quant_hypothesis(action=add)      ② 登记可证伪假设 + 可在存量数据上执行的 spec
      ↓
scripts/run_research.py           ③ 统计裁判：DSR / PBO / CPCV / 2× 成本 / 容量
      ↓
quant_hypothesis(action=list)     ④ 读判决：rejected / testing / promoted
      ↓
quant_memo(action=add)            ⑤ 写备忘录：机制、失效条件、带概率的预测
      ↓
scripts/score_memos.py            ⑥ 到期结算，算 Brier 分数
```

**关键约束**：第 ③ 步的判决由代码给出，模型改不了；第 ⑥ 步的分数也是代码算的。
模型唯一能自由发挥的是 ①④ 之间的推理，以及 ⑤ 的书面判断——而这两件事**都会被后续数据打分**。

## 3. 什么叫"想得好"

不是文采，是三条可检验的性质：

1. **机制是因果的，不是相关性的转述**
   - ❌ "宽度低，历史上之后涨，所以看涨"
   - ✅ "宽度低说明多数个股跌破自身均线，止损与赎回的卖压集中释放；指数级买盘先修复指数、个股滞后，所以只在指数上做"
2. **必须能被证伪，而且证伪条件是可观测的**
   - ❌ "如果市场情绪转弱则失效"
   - ✅ "若未来 10 个交易日宽度仍低于 25% 且等权指数创 60 日新低，则判断错误"
3. **概率必须敢写，并且事后可结算**
   - 每条预测带 `kind`（market_up / symbol_up / core_up）、`horizon`（交易日）、`probability`
   - 结算规则固定，模型无法事后解释

**评分口径**：Brier = 平均 `(概率 - 结果)²`。永远给 0.5 的模型得 0.25，等于什么都没说；
自信且正确 ≈ 0.05；自信且错误 ≈ 0.9。校准表按概率分桶，看"说 70% 的时候实际发生了几成"。

## 4. 反模式（写进契约，违反即无效）

| 反模式 | 为什么错 | 系统如何拦住 |
|---|---|---|
| 让工具给"推荐买入" | 把判断外包给规则，模型退化成排序器 | `quant_screen` 只返回候选与事实，不返回建议 |
| 编造价格/涨跌幅 | 数字幻觉 | 所有数字必须来自工具；提案里没有价格字段 |
| 用"这次不一样"解释亏损 | 不可证伪 | 复盘必须引用 case id 与失效条件 |
| 一次提 20 个假设 | 多重检验，必然过拟合 | 裁判按试验数做 Deflated Sharpe |
| 把 backtest 的 Sharpe 当预期收益 | 忽略成本与容量 | 强制 2×/3× 成本压力 + 容量检查 |
| 只在赚钱时写 memo | 选择性记录 | memo 按时间戳入库，`score` 全量结算 |

## 5. 当前边界（诚实清单）

- **裁判覆盖股票事件研究与可转债**（涨停池/炸板池/跌停池/全市场涨跌幅、`pool="cb"`、
  `cb_link`）。指数层面的择时与 ETF 轮动没有对应的 spec 类型，仍进不了裁判。
- **T+0 品种**：可转债日线已入库（2023-01 起，`cb_daily`），交易台按 10 张/手、T+0、
  免印花税表达，并有端到端票据测试（2026-10-29）。**分钟线仍缺**，跨境 ETF 溢价率也没有，
  所以"日内反转只能在 T+0 收割"这条判断能验证到日频，验证不到分钟级。
- **校准样本为 0**：预测需要 5–20 个交易日才结算。Brier 分数要等到 2026-11 才有第一版。

## 6. 给模型的操作清单

盘前：
1. `quant_context` 看数据是否可用、账户状态、风险开关。
2. `quant_discover` 读事实；**先问"哪一条最反常"**，不要先问"买什么"。
2b. 需要更细的切片时用 `quant_universe` 自由浏览（换手率、量比、流通市值、PE/PB、行业、
    20 日区间位置）。它只给事实，排序仅用于显示——选谁、为什么，是模型的判断。
3. 若发现可检验的机制 → `quant_hypothesis(add)`；跑裁判；读判决。
4. 若只是形成观点 → `quant_memo(add)`，必须带失效条件与概率。

盘中：
5. 只有 `quant_propose` 一条路；被 guard 拒绝时解释原因，不要换参数重试。

盘后：
6. `quant_journal_append` 写复盘；`quant_memo(score)` 结清到期预测；`quant_arena` 看自己
   相对市场与核心盘的位置——**少于 20 笔平仓，不许声称有 edge**。
7. 若某条规则被反复证伪，`quant_playbook_propose` 出草稿，等人激活。

## 7. 判据：这套东西有没有用

三个月后只看三个数字：

| 指标 | 及格线 | 含义 |
|---|---|---|
| 备忘录 Brier | **< 0.22** | 概率比瞎猜（0.25）好 |
| 校准偏差 | 每桶 \|预测-实际\| < 0.15 | 说 70% 时真的七成 |
| 被证伪假设占比 | 20%–50% | 太低说明假设不可证伪，太高说明机制是编的 |

如果 Brier 一直在 0.25 附近，说明模型的"深度思考"没有信息量——那时应该关掉它，
只保留规则与裁判，而不是继续给它加 prompt。
