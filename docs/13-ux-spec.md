# 量化台前端 · 体验规范（Phase 2）

范围：信息架构、任务流、状态规范、键盘与密度、风险防护。
不含视觉样式细节（见 Phase 1 视觉方向）与实现代码。
所有数字与文案必须能在这 93 条接口里找到出处；界面不得承诺接口没有的东西。

## 1. 导航模型

一级页签 6 个，一个页签 = 一个用户问题：

| # | 页签 | 回答的问题 | 主要接口 |
|---|---|---|---|
| 1 | 今日 | 今天做不做、做哪只 | `/facts` `/market/pools`(gates) `/regime` `/risk` `/research/screen` `/tickets?status=open` |
| 2 | 盘面 | 钱在往哪走、有没有我要的形状 | `/market/sector` `/universe` `/market/frame` `/watch` `/market/pools?group_by=industry` |
| 3 | 持仓与风险 | 手上这几只现在安不安全 | `/risk` `/risk/exposure` `/risk/stops` `/portfolio` |
| 4 | 决策 | 哪些票在等我、为什么被拒 | `/tickets` `/tickets/{id}` `/decisions` `/declined` `/journal` |
| 5 | 复盘 | 今天哪条判断被数据推翻了 | `/facts`(收盘) `/journal`(verified) `/attribution` `/decay` `/arena` `/duty` |
| 6 | 内核 | 这个台子现在还值得信吗 | `/health` `/data/status` `/readiness` `/usage` `/persona` `/observations` |

**个股页**是第 7 个界面但不是页签：从任何列表点进去的二级页面，带符号路由 `#/s/600000.SH`，可回退、可收藏、可直开（含 `document.title`）。

**路由命名以实现为准，不再改**：`today / market / risk / decide / review / kernel`（`market`、`risk` 与页签"盘面""持仓与风险"是同一个东西，hash 里的词用户看不见，不值得为对齐文案改 6 个文件）。硬要求只有两条：① 一级路由恰好 6 个 + `s/` 二级；② `#/s/600000.SH` 直开可用，旧 `#/stock?symbol=` 做一次 `location.replace` 重定向，内部跳转统一走 `navigate()` 一种形状。

**顺序理由**：按一天的三个时刻排，不按后端模块排。09:26 打开落 1，盘中落 2/3，18:50 落 5。
**默认落地页按时段**：`<09:15` → 今日；`09:15–09:30` → 今日（盘前态）；`09:30–11:30 / 13:00–15:00` → 盘面；`>15:05` → 复盘。用户手动切过页签后，本次会话内不再自动跳转（防抢焦点）。

**为什么不按后端模块分**：
1. 后端按数据源和延迟切（`/facts` 是收盘包，`/market/frame` 是最后一帧，`/market/pools` 是另一个进程落的分区），模块页会让用户在三个数字之间自己对齐时刻——而这正是他零容忍的地方。
2. 一个问题会被多个模块回答（"今天强不强"分散在 `/facts.breadth`、`/market/pools.sentiment`、`/regime`、`/market/frame.delta`），按模块分就要在四处重复讲同一句话。
3. `/usage` 里 `/knowledge` 被调了 3574 次——那是模型在拼装答案，不是人的浏览路径。模块导航等于把模型的工作台端给用户。

**全局镀铬（不属于任何页签，每页常驻，一条 28px 状态条）**：
常驻 6 项（变化的、与"能不能动手"相关的）：`交易日/时刻` · `数据时刻（收盘 11-06 / 帧 8m12s 前 / 实时）` · `gates 三态` · `kill-switch / safe-mode` · `待批票计数` · `熔断三源`。
收进 `⋯` popover（稳定的、纯参考的）：`readiness` · `当前人格` · `账本 revision` · `fill_mode`。
- 端点耗时**不进状态条**，归内核页（性能是"想查时查"，不是"每秒要盯"）。
- 待批票数为 0 时不占位（省宽），>0 才出现并带计数。
- **升级规则**：popover 内的项一旦异常（`readiness ≠ READY`、`fill_mode` 偏离预期口径），自动升回常驻位并加**琥珀三角**——省宽度不能省掉"现在不能写收盘报告"或"盈亏口径不是你以为的那个"。
  `fill_mode` 尤其要这样：它决定成交按什么价撮合，直接改变盈亏数；口径悄悄变了却不提示，是"数字看起来对但换了个意思"的典型。
- 人格收进 popover 不影响正确性：提案表单内就近显示"当前人格 = X，与票据不符会被拒"，比放在状态条里更有用。
- 状态条底边 3px 是数据新鲜度尺（视觉稿），状态条整体可点击跳到 内核 页。
它存在的原因：**任何一页的任何数字，都必须能在一秒内回答"这是哪个时刻的"**。

## 2. 每页信息架构

列定义（1440 内宽约 1300px，12 列栅格）：**L 左列 = 3 列宽（约 300px）**、**M 中列 = 5 列（约 520px）**、**R 右列 = 4 列（约 420px）**。
标注：`[首]` 首屏必须（1440×900 不滚动可见）；`[滚]` 滚动可见；`[次]` 次级（抽屉/折叠，不进主滚动流）。

### 1 今日
- 状态条（全场宽，28px）`[首]`
- L：账户与额度（equity / cash_free / 持仓数 `n/3` / 今日已用动作 `k/max` / 单票上限 / 行业上限）← `/risk.limits` `[首]`
- L：闸门（`sentiment.gates`：`tone_ok / break_rate_ok / height_ok` 三项，每项三态 `true / false / null`，附 `phase` 与 `note`）`[首]`
  - `ok=null` + `indeterminate=[no_panel]` → 走**缺数**样式（灰虚线框），不走"阻"；显示 `note` 原文「三池没入库，闸门无法判断；这不是'闸门不过'」+ `why_indeterminate` 原文
  - `borderline` 非空（派生 0.3494 / 厂商 0.3596 夹住阈值）→ 该格竖排**两行**（同底色、同字重 400、无分隔线）：`派生 34.94% / 38% −3.06pp`、`厂商 35.96% / 35% +0.96pp`，尾行 `两口径相悖 · 内核不仲裁 · 无唯一答案`。
    该格的**判定位留空**（空槽虚线方），不画过/不过——这比"一行过一行不过"诚实，也自动满足"不许高亮其中一行"。
  - `tone_note` 非空（tone=主升 但 gates 不过）→ 面板下方原句「强到还能封板，弱到不宜开新仓」，中性底、两行并列、不分主次（全站唯一允许并置矛盾的组件）
- M：三池（涨停 / 炸板 / 跌停，Tab 切换不换页；表列：名称、封单、首封、连板、一手成本、占净值比）`[首]`
- M：可买三问（`cap=15元` / `in_cap=25` / `one_word` 三个独立计数，**不许合并成一格**）`[首]`
- R：宽度与体制（breadth 涨/跌/平、`regime` stressed/down、vol 分位、宽度值、`delta` 与 N 分钟前相减）`[首]`
- R：今日票据摘要（前 5 行，点击进决策页）`[滚]`
- 全场宽：规则候选 3 只 + 每只的 `why` 原文 `[滚]`
- `[次]` 昨日收盘事实包（`/facts` 按日期的完整键值）
- 共享数据：`/facts` 一份喂「可买三问 + breadth + 账户兜底 + 票据计数」。**三池计数只用 `/market/pools`**（同源含 `age_seconds`、`phase`、`gates`），`/facts` 的池计数只在复盘页以"收盘事实"身份出现——一屏内同名数字只允许一个来源。

### 4 决策
- L（5 列）：票据表（`ticket_id`/时间/方向/代码/`qty` 或 `target_weight`/`status` 枚举/`directed_by`）`[首]`
- R（7 列）：选中票详情——`guard.checks` 全表（`name / ok / detail`）+ `thesis`/`evidence`/`invalidation` + 操作区（approve / reject / cancel）`[首]`
- R 底部：操作语义说明（propose 不出钱；approve 才动钱；reject 关提案；cancel 撤挂单；armed 票两者都置 cancelled）
- 状态机：视觉上可以是 4 段 stepper（proposed → queued → filled → 终态），但 **`armed` 必须是 proposed 之后向下的分叉支线**（冻结待触发、不出钱、可 reject 或 cancel），不能并进 queued；详情区第 1 行永远显示后端原始 `status` 枚举，step 位置只在图上。
  **`当前` 段用左侧 2px 竖条 + 600 字标记，不用「实心方」**——实心方+600 已被"判定不过"占用（§4 第三条通道），两处复用同一个字形会让"闸门不过"和"票在第 2 步"看起来像同一件事。方只归判定，圆与条只归位置。
  终态 `rejected / cancelled / expired` 三个**不染色**（它们不是"坏"，是"结束了"），末段用虚线空心方 + 原字符串。
- `[次]` `/decisions` 审计行、`/declined` 长文本记录、`/journal` 与本票关联的核对结果
- 共享：`/tickets?view=brief` 列表；选中后单取 `/tickets/{id}`（full 票 2.8–3.8 KB，不预取全表）。

  高度分解（**只有一份定义，写死在 `chart.js` 的 `GEO` 常量里，别处不许出现第二份**）：
  ```
  宽态  6 ｜ 228 主图 ｜1｜ 58 量 ｜1｜ 66 副图 ｜ 20 轴区 = 380
  窄态  6 ｜ 295 主图 ｜1｜ 58 量 ｜ 20 轴区           = 380   （有效宽 < 880）
  ```

- 上带（右，R = 420px，`sticky; top:44px`，高 728px，贴满 44→772）：执行测算（`/execution/estimate`：qty → 冲击成本 bps + 拆单条数）`[首]`；提案入口（**全站唯一入口**）`[首]`

- 下带（图下，宽 1018，**4 等分 × 253px**，随页面滚动）：13 块按 `BLOCK_ORDER` 排，**密度分档跨列**——

## 3. 三条核心任务流

### a) 盘前 09:26：今天做不做、做哪只
1. 打开 → 今日页。状态条读 `/health` + `/market/status` + `/readiness`，显示「盘前 · 数据为 11-06 收盘 · 帧 15h12m 前」。
   反馈：用户立刻知道"这不是实时"，不会把昨天的 breadth 当今天。
2. L 闸门读 `/market/pools?date=上一交易日`。若 `gates.ok=null` 且 `indeterminate=["no_panel"]`，原样显示后端 note：「三池没入库，闸门无法判断；这不是'闸门不过'」，并折叠"可做/不做"结论区。
3. M 三池 + 可买三问读同一份 `/facts`/`pools`：`涨停 33 / 炸板 17 / 跌停 15`，`cap 15元 → in_cap 25 / one_word`。
4. R 体制读 `/regime`：写「波动处于过去 750 日的第 92 分位」「宽度 0.331」，不写"高风险"。
5. 页底规则候选读 `/research/screen`：3 只 + `why` 原文。点一行 → 个股页（走 b）。
6. 若 0 只：不显示空白，显示「`max_price=15` 下 5379 只里 0 只满足规则」+ 一个「去盘面按行业/成交额筛」的按钮。
7. 若已有 proposed 票：R 栏置顶一张「等你审批」条，点击进决策页（走 c）。

### b) 个股研究：看完 K 线与指标再决定提不提案
1. 进入个股页 → `GET /symbol/{s}/profile?sections=identity,tradability,valuation,peers,relative_strength` 先出首屏；其余 8 块按需 `sections=` 拉，**每块自带 `as_of` 与被省略原因（null 时给原因，不给 0）**。
2. `GET /market/bars?days=60` → 日线 + 前复权开关；`GET /market/mins` → 5 分钟 + VWAP。两图共用同一时间游标，光标读数在图上显示同一时刻的价格。
3. 读 valuation 分位 + ATR20 + 年化波动。界面做**算术**不做判断：「ATR20 = ¥0.29 → 1R 距离 ¥0.29，按 5000 净值 1R 风险 1% 对应 172 股」，并注明这是算式不是建议。
4. 在 R 栏填 qty → `GET /execution/estimate`：显示冲击成本 bps、拆单条数、往返固定成本。若最小佣金 bps 超 `min_ticket_bps`，就地显示「这笔单往返固定成本 ≈ X bps」。
5. 决定提案 → 点 R 栏「提案」（全站唯一入口）→ 表单：`symbol`(锁定)、`side`、`sleeve`、`thesis`(≥20 字，实时显示剩余字数)、`evidence`(≥1 条，可增行)、`invalidation`(≥5 字)、`qty` **或** `target_weight`（选一个后另一个禁用并说明"两者意思是两个不同意图"）。提交按钮写「生成票据（不出钱）」。

### c) 提案 → 审批
1. `POST /decision/propose`，自动带 `client_request_id`（本地生成并缓存，超时重试原样重发）→ 返回 `status=proposed`，界面弹「票据已生成 #t-xxx，尚未占用资金」。
2. 若 409：**不渲染成网络错误**。显示 `code` + `message` + `guard.checks` 全表：红行 = 失败项，写明 `detail` 原文；顶部一句固话「改 body 不会解决这一条，请先处理它」。若是 `TRIGGER_DISABLED`，显示后端原文与"关闭时提交会留 proposal_blocked 记录"。
3. 若 422：定位到具体字段（后端 `extra="forbid"`：多字段、少必填都 422），高亮该输入并保留用户已填内容。
4. 待批票计数进状态条常驻，并在决策页 L 栏置顶。
5. **审批二次确认**（唯一资金动作）：弹层复述 `symbol / side / qty / 预估金额 / 占净值% / 止损价 / 现价时刻与 is_realtime`，需显式勾选或键入 `confirm` 才发 `POST .../approve {confirm:true}`。弹层默认焦点在"取消"上。
6. reject 与 cancel 的按钮文案必须不同：「否决提案（票据作废）」vs「撤回挂单（不成交）」；armed 票两者都置 cancelled，需在按钮下方一行说明。
7. 成交后：`/orders` 出现行、`/risk` equity 变化、可写 `/journal`。界面显示终态，不显示"成功"这种没有对象的话。

## 4. 状态规范

禁止「暂无数据」「加载中」，每条都要说清**是什么、为什么、下一步**。

**三条正交通道，一问一通道**（视觉稿定稿）：

| 回答什么问题 | 编码方式 | 取值 |
|---|---|---|
| 价格方向 | **色相**（只有红/绿/平灰） | 涨 `#FF5A63` / 跌 `#21C97C` / 平 `#8A93A3` |
| 这份数字可不可信 | **色相 + 形状** | 灰虚框（缺数=待补） / 琥珀斜纹+三角（旧） / 紫反白（系统坏） |
| 判定过不过 | **形状 + 字重，零色相** | 过 = 1px 空心方 `#7C8899`+400；不过 = 实心方 `#E6E9EE`+600；**没有结论 = 空位 + 一句原因，不画方** |
| 时间是走是停 | **青** `#3ED3B8` | **只 4 处**：状态条 live 点、新鲜度尺 T0、pipe-step.done、profile「实时」。青↔琥珀是时间轴两端（在流 / 已停），**青不表示"成功"** |

**形状总则：每个形状只回答一类问题，不按"状态"分工、按"问题类型"分工。**
先问「这是哪类疑问」，形状就定了，不需要讨论。任何新形状上线前还要答第二问：**它是否和已有形状在同一位置、同一色相上表达两件事？** 答"是"就不许上。（"方"之所以撞了四次，是因为它最初只是个"醒目的标记"——凡是"醒目"当理由的形状，最后都会撞。）
**顺序反过来才对：先问"这事有没有比形状更省的办法"，都不行才动形状。** 七级顺位，越右越贵：
**文字 > 空位 > 位置 > 尺寸 > 填充 > 线型 > 新形状。**
这一轮每次出事都是跳级：想要形状（跳过文字）→ 形状不够补尺寸（跳过填充）→ 填充不够补线型（跳过空位）。有这条序，下次不用讨论，取第一个够用的即可。**越往右，占的注意力越多**——形状占的是注意力预算，而用户每天只有三次、每次几分钟。所以属性值域可以空着（零成本），形状表不能有空行（每次都要多看一眼去确认"这个形状是什么意思"）。

| 形状 | 回答的问题 | 占用者 | 尺寸 |
|---|---|---|---|
| **方** | 二值判定（是/否） | 过 = 1px 空心 / 不过 = 实心 | **8×8**，只在 guard/闸门的固定判定位 |
| **圆** | 离散状态点（走到哪 / 这路通不通） | 状态机位置（实心=已完成 / 空心=未达 / 虚线=终态）；状态条源健康（青=在流 / 空心=待命 / 紫=断） | 6px |
| **条** | 累积级别（1→2→3） | L1 单紫条 / L2 双紫条；当前项白条 | 2×12px |
| **三角** | 时间：这个数旧了 | stale | 3px 直角边，贴读数右下角、间距 2px |
| **斜纹** | 部分性：只到一部分 | 部分降级（琥珀，容器叠底）/ 炸板（红，图表元素） | 两族不同视口层 |
| **虚框** | 缺失：这里没东西 | `—` / 整格 / 面板 三级；也用于"整体无数据"的判定格 | 48×20 / 96×56 / 面板 |
| **空位** | 没有结论（不是"否"，也不是"没东西"） | 判定无结论 / borderline 相悖 | 保留格宽，不画任何形状 |
| **文字 chip** | 离散的具名状态（封住 / 不可买） | 涨停 / 跌停 | 跟随行高，颜色只用 `--px-up/down` |

**"方"只剩一个占用者、两种状态**：8×8、只在判定位、空心=过 / 实心=不过。**没有第二种尺寸，6×6 涨跌停方已取消**——涨停/跌停改用**文字 chip**（"涨停"/"跌停"），含义由字承担、颜色只是冗余强化。这样"方"再没有混淆空间，也符合"颜色不单独承载语义"。
**判定必须"填充量随严重度递增"**：过 = 空心（最轻），不过 = 实心（最重）。理由是 25 格里 23 格是"过"——若"过"实心，矩阵 92% 是一片白噪声，真正要看的 1 个"阻"要靠 1px 描边去找，而 8px 格子上 1px 描边在 DPR 1.25 抗锯齿后基本看不见。扫一眼应是"一片空心里有几个实心"。
这与"正常态不占墨"同源（状态条"通"用灰不用青、`.chip.ok` 中性、`.approve` 圆点用灰）——**正常态一律最轻**。

**"没有结论"统一用空位，不画方、不用第三种线型。**
`无判`（indeterminate / 面板未成形 / 分母为 0）、`未运行`（检查没跑）、`borderline 相悖`三种情况，视觉上**是同一种东西：格子在，方不在**，原因由旁边一句文字承担（`未运行`、`无唯一答案`、`未入库`）。
理由：8px 上**实线可靠、虚线勉强、点线不可分**——用线型去分三种"没有结论"必然失败；而"空位"与"实心方"的差别是一眼可辨的，正好接住 2026-10-30 那类"把没得判读成不过"的事故。
合并的第二个理由：这两种状态**对用户的下一步动作没有区别**（都意味着"这格不能当答案"），而"为什么"决定他去补数据还是跑检查——那是文字的事。用两种形状表达同一句话，会暗示这是两种可操作状态。

**空位的两个实现条件（否则"空位"会退化成"看不见"）：**
1. **占固定槽位**：矩阵 `grid-template-columns: repeat(5, 8px)`，空位不参与流式塌陷。"空"必须是"这一格没结论"，不能看起来像"根本没有这一格"——那正是 10-30 的错觉。**格子在，方不在。**
2. **原因必须有两个出口**：可见文本一句（≤4 字）+ `aria-label` 完整句。**空位本身不挂 `title`**（8px 命中率极低），原因挂在**格子的容器**上。
3. `--mark-muted: #5E6B80` 只做**描边色**（终态虚线圆、空位容器内残留参考线），**永不做文字色**（3.3:1 不够正文）。

**形状 token（唯一一套，全部 `--mark-` 前缀，冻结不派生）**：
`--mark-judge:8px` · `--mark-judge-stroke:1px` · `--mark-gap:6px`（方与旁侧文字间距）· `--mark-stale:3px` · `--mark-bar-w:2px` · `--mark-bar-h:12px`。
**没有 `--mark-price`**：6×6 涨跌停方已取消，表里没有的形状不该有 token——变量本身会变成"空位"，会被人拿去用。实现里不许出现 8 / 6 / 3px 这类魔法数。

**红绿只有一对**：`--px-up #FF5A63` / `--px-down #21C97C`。**删除 `--limit-up #FF3B4E` / `--limit-down #12B36A`**（深红在面板上只有 5.22:1，比 `#FF5A63` 的 6.01 更糊，"更重"是错觉）。
涨停/跌停用**文字 chip**（"涨停"/"跌停"，`--px-up/down` 作色，含义由字承担）；K 线一字板 = 2px 粗条 + 轴标签 2px 左色条；参考线 dashed 不变。

**三池三柱**：涨停 = 实心红 / 炸板 = 红斜纹 / 跌停 = 实心绿。炸板是价格事件（封住被打开），归价格层，**不用琥珀**——这样琥珀独占"数据旧"，今日页上"炸板柱"与"stale 角标"不再同色。
熔断三源用**圆点**不用方：正常 = 1px 空心圆 `#37414F`，熔断 = 实心紫圆 `#B98CFF`。"源健不健康"是同一个问题的三种答案，与状态条青点同族同尺寸、靠色相分。

**反白实心只做"告警块"一种载体，不做按钮填充**。危险动作（清仓 / 否决 / 撤回）不占色相——色相已被三条通道占满，"不可逆"是交互属性，颜色表达不了：
`1px --line-strong #37414F 描边 + 600 字 + --ink（不染色）`，**hover 反相**（底 `#E6E9EE`、字 `#0B0D10`，全站唯一反相 hover），点击**原地变「再点一次确认（3 秒）」**，倒计时用底部 2px 条从 100%→0（`--ink-2`，不用颜色不用抖动），3 秒不动自动回退。
按钮梯度：**全屏 1 个实心（approve 的 accent）→ 最多 1 个反相 hover（危险动作）→ 其余描边**。

**缺数四档（同族，四种量级）。核心判据：标注次数应与"原因的数量"成正比，不与"缺失格的数量"成正比。**
12 格缺是同一个原因，标一次就够；标 12 次会把"缺数"从信号变成纹理。

| 档 | 形态 | 用在哪 |
|---|---|---|
| **格** | 单格虚框（≥48×20，`--ink-2`） | 这一格没取到，原因可能各不相同 |
| **列** | 列头下方 1px dashed `--al-missing-line` 通栏；列内全部 `—`（`--al-missing-ink #AEB7C4`），**不带框、不定色** | 父值缺失、整列不可算（equity → 仓位/单票/行业/现金） |
| **格块** | 虚框 ≥96×56，底 `rgba(255,255,255,.035)`，主行 + 副行写缺什么 / 谁能补 | 闸门这类成块不可判 |
| **面板** | 虚框 + 居中两行 + 一行补数命令 + 描边按钮「补数据」（不占用全屏唯一的实心 accent） | 三池整块没入库 |

- **整列用"一条线替你 12 个框"**：3 个 1px dash 在视觉上就等于"这一列作废"，而 12 个虚线框会变成网格纹理——那时用户看到的不是"缺数"，是"这个界面很花"。
- 整列档的三处配套（缺一这档就不成立）：①值不带框不定色；②面板 footer **一行原因、不可折叠**：`仓位/单票/行业/现金 派生自 equity，equity 未取到 → 整列不可算`（这是这一档的存在证明）；③面板右上角用**空槽标记**（8×8、1px dashed、内含 2px 点），**不用琥珀三角**——琥珀留给 stale，两族不混。
- 禁止：插图、居中大标题、`--ink-4` 淡化、任何动画。**缺数是待办，不是空状态页。**
- `0` 是干净数字（`--ink-2`，无底纹无边框，`0.00%` 不染色），与 `—` 一瞥可分。
- **三态渲染是一个共享原语，不是表格的私有逻辑**：`null`/`''` → 带框 `—` + 原因；`0` → 干净 `0`。表格单元格、账户键值行、闸门数值、体制分位、KPI 条**全部**走同一个函数（`ui.numCell(value,{asOf,age,source})`）。
  只在 `table()` 里硬编码这条，独立数字字段就会各自兜底——而那些字段（equity、回撤、breadth、分位）恰恰是最容易被读错的地方。
- **缺失要级联，不许用兜底分母算出"看起来正常"的百分比。** 派生数字的父值缺失时，子值一律 `—`。
  `Number(equity) || 1` 是个典型：equity 为 null 时分母变 1，占净值比会变成几万个百分点或被 clamp 成 100%——**两种结果都比 `—` 糟**，因为一种荒谬、一种看起来完全正常。
  同理：`Number(x) || 100`（空输入给默认手数）会把用户输入的 `0` 变成 100，必须写成 `value === '' ? 100 : Number(value)`。
  **整列缺失的形态**：占比类（仓位 / 单票 / 行业 / 现金）随 equity 一起缺时，**整列变 `—` + 列头一条 1px 虚线 + 面板 footer 一行原因**（见下"缺数四档"），不逐格加虚框——一屏全是框等于没有告警。
- **兜底数字形态一律视为缺陷**：`|| 1`、`|| 0`、`?? 0`、`Number(null)`。判据：这个 falsy 兜底会不会把"没取到"变成"取到了 0"。会，就是缺陷。
- kill-switch active / safe-mode on 属**常态系统状态**：紫 2px×12px 竖条、无底（L1）；单源降级 L2 = **双紫竖条**（不借"方"，方已被判定与涨跌停占用）；**反白块只留 L3**（全源熔断 / 500 / 进程死亡）。三级紫梯的判据里**不出现"数据没到"**。
- **「条」的两个归属靠位置分开**：白条只出现在**列表行内**（状态机当前段、清单项）；紫条只出现在**容器左缘**（面板、chip、状态条项）。位置不重叠、色相不同，不误读。
- 时间线终态 `rejected / cancelled / expired` 无色相：1px 虚线圆 `#5E6B80`，原字符串照写——"结束了"不等于"坏了"。
  状态机四个状态全是圆和条、**一个方都没有**：已完成 = 6px 实心圆 `#7C8899`；当前 = 2px 白条 + 600 字；未达 = 1px 空心圆 `#37414F`；终态 = 1px 虚线圆 `#5E6B80`。
- inline code（`.err .code` 这类）不承载告警，中性底 + `--ink`；告警只在外层容器上。
- **灰与紫的边界不许模糊**：闸门整块不可判永远是灰（数据组），即使"补不了"也只是灰里加一行「补不了，用昨日终值」；紫只留给 breaker / 500 / 全源熔断。2026-10-30 的折叠事故就是这两族混用的结果。

| 状态 | 界面 | 文案 |
|---|---|---|
| 加载 | 骨架行 + 计时 | 「正在取 三池…（1.2s）」；>3s：「仍无返回。可点重试；这一格不会用旧值填充」 |
| 真无（后端给 0） | 正常数字 0 + 一句来源 | 「今日涨停 0 家（`/market/pools` 11-06 收盘）」 |

| `f` | 筛选条展开/收起（盘面、决策） |
| `?` | 快捷键表；`Esc` 关抽屉/弹层 |

审批弹层内：`Enter` 不提交，必须 `Ctrl+Enter` 或勾选后点确认——防止连按 `a` 两次直接成交。

**列数策略**（高度预算已与视觉稿对齐：顶栏 44 + 页签 32 + 状态条 28 = 镀铬 104；900 − 104 − 底栏 24 = **主区 772px**）
- **1440×900**：L 300 + C 718 + R 420（1px 竖分隔线，非 gutter）。表格行高 24px，字号 12–13px，单屏表格 ≥14 行。全部 `[首]` 面板必须在此不滚动可见。
  - 预算校验：今日页 C 列 三池 12 行(288) + 表头/池 Tab(88) + 可买三问(80) ≈ 456 ≤ 772；L 列 账户(200) + 闸门(200) ≈ 400；R 列 宽度体制(180) + 票据 5 行(160) ≈ 340。三列都留余量，"规则候选"因此落 `[滚]`。
- **1920×1080**：16 列 = 3 / 5 / 4 / 4。多出的一列放「执行测算 + 票据详情」，表格行升到 ≥20 行。**不放大字号、不加留白**，只加列数与行数（密度优先）。
- **1280 及以下**：L 280 / R 380 / C 620；<1100 时 R 收进右侧抽屉，C 独占，不做三列压缩（三列在 1100px 内会把数字挤成两行，对比度失效）。
- 触控（≥1024 平板）：行高 40px，`j/k` 失效，列表行尾出「⋯」菜单；关键数字保持左对齐、单位固定在列头。

**长表与内滚动（`.fit`）——只允许 4 处，因为嵌套滚动是滚动陷阱**
表头 `sticky` 必须有最近的滚动容器才能生效，所以长表要 `max-height: calc(var(--main-h) - 140px)` 自行滚动。规则：

| 位置 | 用 `.fit` | 理由 |
|---|---|---|
| 盘面 · 全市场（5379 只） | 是 | 不内滚会推走全部 `[首]` 面板 |
| 盘面 · 31 行业表 | 是 | 首屏必须可见，且要能吸顶排序 |
| 决策 · 票据表 | 是 | 待批票要一直在视口内 |
| 内核 · 数据集全表 | 是 | 同上 |
| 今日 · 三池（12 行 × Tab） | 否 | 一池 12 行 ≈ 288px，天然装得下 |
| 持仓 · 持仓表 | 否 | 最多 3 个持仓，`max_positions=3` |
| 复盘 · `/facts` 分组 | 否 | 不是表格，用折叠 |

- `.fit` 必须给"下面还有"的提示，而且是**三件套同时出现，缺一不可**（深色底上单靠滚动条等于没有提示；只加渐隐又会被读成"面板边缘虚化"，而我们全站没有虚化，只有硬边）：

  | 元素 | 规格 | 作用 |
  |---|---|---|
  | 12px 渐隐 | `linear-gradient(to bottom, transparent, var(--fade-bg, var(--bg-panel)))` | 暗示"下面还有" |
  | 「还有 N 行」 | 11px `--ink-3`，底 `--bg-raised` + 1px `--line`，圆角 3px，padding 2px 6px，距底/右 8px | 报**事实**，不报像素 |
  | 滚动条 | `scrollbar-width:thin`，thumb `#37414F`，hover `#4E5A6B`，WebKit 6px | 可操作性 |

  **渐隐底色由容器声明，不写死、也不用 JS 读**：`.panel--raised .fit-fade{ --fade-bg: var(--bg-raised) }`。任意新底色都能用。
  **禁用 `mask-image`**：它能自动适配任意底色，但会给 5379 行的滚动容器加一层合成，滚动掉帧——代价比这条渐变大得多。

  **渐隐与 N 行必须在滚到底时消失**（`scrollTop ≥ scrollMax − 4`）。永远显示"还有"就是在撒谎，而这个产品的全部价值就是不撒谎。`N = ceil(hiddenPx / 22)`，完整行数；`N = 0` 时两者一起隐藏。
  渐隐的底色取**所在容器声明的变量**（见上），不写死也不用 JS 读。
- **N 的刷新不靠事件**：把 `updateFit()` 挂在**渲染结束那一行**（每次刷新都要重画行），再配一个 `ResizeObserver` 覆盖窗口缩放。**不用 `MutationObserver`**——它会和数据渲染互相触发。
- 高度走 token，页面里不出现魔法数：`--fit-max-h: calc(var(--main-h) − 120px)`（120 = 面板头 32 + 表头 22 + 汇总/操作 24 + 缝隙 42）、`--fit-min-h: 220px`（≈10 行）、`--fade-h: 12px`。
  **低于 `--fit-min-h` 时不内滚，改整块折叠**（`details`）——10 行以下的内滚区比折叠更难用。
- **同屏第二个 `.fit` 自动降级**为 `max-height:none` + 整页滚动。写成规则，不靠人记。
- sticky 表头**必须不透明**（`--bg-panel` + `inset 0 -1px 0 var(--line-faint)`）。半透明表头会让行从下面透出来，在密集表里比没有表头更糟。

**内滚区的键盘规则：按"这张表能不能做事"分两种，类型由 IA 标注、不许实现时临时决定**

| 类型 | 判据 | 焦点模型 |
|---|---|---|
| **可操作表** | 点行有反应（进个股 / 按行业筛 / 开详情） | **行 roving tabindex**（同屏只有 1 行可聚焦），容器**无 tabindex** |
| **纯读表** | 点行什么也不发生 | **行不可聚焦**，容器 `role="region"` + `tabindex="0"` + `aria-label`（唯一停靠点，只用于键盘滚动） |

判据一句话：**焦点存在的前提是这里能"做"事；只能"看"的表，焦点只该有一个入口。**
本台 4 处 `.fit` 全部是**可操作表**（全市场 → 进个股；31 行业 → 按行业筛全市场；票据表 → 开详情；数据集全表 → 看 manifest/lineage），因此都用 roving；纯读模式保留为规则，供后续新增表使用。

**表类型写进 DOM，不写进记忆**（否则还是靠人记）：
```html
<div class="fit" role="region" aria-label="申万一级 31 行业" data-row-action="filter">
```
`data-row-action` ∈ `open | filter | select | none`：
- `open / filter / select` → 行 roving tabindex，容器**不带** tabindex（周检查：容器与被聚焦行不得同时有 tabindex）。
- `none` → 行不可聚焦，容器 `tabindex="0"`。
- **缺这个属性时渲染即报错**（dev 抛错 / 生产 console.error + 按 `none` 兜底）。"这张表能不能点"是 IA 的标注，必须是数据属性，不能是写代码的人当场拍。

**刷新时的视线不能被人抢走**（交易台一天看三次，每次被顶掉一行是不可接受的）：
- 判"还有多少"用 `scrollHeight − clientHeight`，**不依赖 `scrollTop`**（行数变少时浏览器会夹紧它）。
- **刷新前的锚定要做三件，只做前两件等于没做**：
  1. 记 `activeKey`（`document.activeElement.closest('[data-key]')?.dataset.key`）与首行 key；
  2. 渲染后按 key 恢复 `scrollTop` **和焦点**；
  3. 恢复焦点用 `focus({preventScroll:true})`，否则与第 2 步的滚动打架，产生二次跳动。
  **丢位置丢的是视线，丢焦点丢的是操作权**——用户正按 `↓` 走到第 3 行，一刷新焦点落回 `<body>`，下一按什么也不发生，他会以为键盘坏了。
- roving 的"当前行"标记也按 **key** 走，不按索引——行数一变索引全错位。
- **聚焦行被刷新删掉时**（票据 filled / cancelled 后从列表消失）焦点不许落回 `<body>`：退到**原位置上一行**，仍不存在则退到第一行。这不是异常路径，票据列表本来就会因成交少行。
- **永远不主动 `scrollTop = 0`**，除非用户自己切换了筛选条件。

- `↑/↓`：移行并 `scrollIntoView({block:'nearest', behavior:'auto'})`（**必须 `auto`**，全站无过渡动画，`smooth` 会让键盘移行有延迟感）；到边界继续滚容器。
- `PgUp/PgDn`：滚一屏。
- **滚轮不劫持**：到底就把滚轮交还页面。
- 行聚焦视觉：`outline:1px solid var(--accent); outline-offset:-1px`。**这是全站唯一允许出现 outline 的地方**——`--accent` 的语义就是"可交互"，焦点属于这一类。不用反相、不用加粗（加粗是判定的字重通道）。
- **焦点环与判定方共存靠几何，不靠自觉**：判定方固定 `left:12px`、8×8；焦点环画在行内边缘（内沿 1px），净空 11px，物理上不可能覆盖。焦点环**不许**改写同行的填充或字重。
- **`scroll-margin-top: var(--row-h)`（22px）必须加在行上**：`block:'nearest'` 不知道 sticky 表头存在，行停在表头正下方时焦点环上沿被盖住，键盘用户会以为焦点丢了。底部有「还有 N 行」chip 时同理配 `scroll-margin-bottom`。

**性能与正确性冲突时，选便宜的那个正确做法。**
所以全站**禁用**（不是"限制使用"）`backdrop-filter` 与 `mask-image`：它们能让观感更对，但会在密集滚动容器上加合成层。写成"禁用"，是因为"限制使用"每次都要重新判断一次，而判断的人不一定知道 5379 行滚动时会发生什么。

## 6. 风险点与防护

**1. 把收盘帧画成实时。** `/facts` 盘中返回的是 `latest_bar_date()`，昨天；真正的"此刻"在 `/market/frame` 的 `frame_age_seconds` / `session.in_session` / `limits.available`。
防护：任何数字必须绑定 `as_of` 或 `age_seconds`；日线类面板标题写日期，帧类面板写「帧 N 分 M 秒前」；超 5 分钟灰底 +「不实时」；状态条常驻"你现在看的是哪一刻"。三个字段缺任何一个都不许渲染成"实时"。

**2. 把"没取到"画成"没有"。** 三池未入库时 `counts` 是 `null` 不是 0；`/tickets` 空要带 `note`；`/watch` 空有两种意思（看过没事 / 没人在看，用 `watcher` 分辨）；`alerts` 是实盘账户、`book_watch` 是 paper 台账，混显会让人把别人的止损当自己的；`profile` 会 `omitted_sections`。
防护：数字三态显示（值 / `0` / `—`），`—` 必带原因与补数方式；"0"只在后端明确给 0 时出现；任何"空"必须回答"为什么空"。

**3. 同屏两个同名数字互相打脸。** 涨停家数在 `/facts`、`/market/pools`、`/market/frame`、同花顺 `/knowledge(topic=limit_structure)` 四处都有，同一天可能 33 / 55 / 61。
防护：一屏内一个数字只有一个来源（今日页三池 = `/market/pools`；`/facts` 的池计数只出现在复盘页，作为"收盘事实"）；跨面板引用一律带「来源 + 时刻」徽标；同屏检测到同名不同值**不静默取最新/取大**，而是在该数字下方并列两行来源——这是特性。禁止 UI 层做静默合并，那是最容易骗到他的地方。

**4. 替用户仲裁。** 后端有多处"两个口径都算对了但结论相反"：炸板率派生 34.94% 过闸门 38%、厂商 35.96% 不过 35%（`gates.borderline`）；`tone=主升` 而 `gates.ok=false`（`tone_note`）；`alerts`(实盘) 与 `book_watch`(paper) 两个账户。
防护：这些地方界面**一律并列，不选边**——两行同权重、共用中性底、各自带口径名与阈值；禁止取平均、禁止显示"综合结论"、禁止默认高亮其中一行。矛盾本身就是信息，藏起来才是在骗他。

**附加：把钱说错。** propose 不出钱、approve 才动钱，两者按钮文案必须完全不同；approve 必须二次确认并复述金额与占净值；`j/k/a/r` 只唤出弹层不执行。

## 7 浮层、焦点与读屏

### 7.1 浮层（modal / drawer）四条硬规则
1. **Esc = 取消，且等价于点遮罩。** 浮层必须在 Esc、遮罩点击、取消按钮三条路径上都 resolve `false`——`confirmAction` 的 `await` 不许挂起。资金动作浮层（approve）按 Esc 后**不得发出任何 POST**，界面留在原票、无状态变化。
2. **焦点三件套**：打开时移入焦点 → 内部 `Tab / Shift+Tab` 循环（首尾回绕）→ 关闭后归还触发元素。初始焦点按场景：`confirmAction` 危险操作 → 聚焦**取消**；`typeWord` → 聚焦**输入框**；drawer → 聚焦**标题**（`tabindex="-1"`，让读屏先读"这是什么抽屉"）。触发元素已消失（列表重排）时退到列表容器。
3. **滚动锁要计数**：打开 `body{overflow:hidden}` 会跳顶，改用 `position:fixed` + 记 `scrollTop` 补偿，或 `scrollbar-gutter: stable`。抽屉里再开弹窗是最常见组合（决策页抽屉 → 点审批），必须按 `depth` 计数，最深那层关闭才解锁。
4. **语义**：普通浮层 `role="dialog" aria-modal="true"` + `aria-labelledby`；资金动作与不可逆操作用 `role="alertdialog"`。背景 `aria-hidden`（或 `inert`）。

### 7.2 分段控件 `.seg`
- 单选语义用 **`role="radiogroup"` + `aria-label`（必填，如「K 线周期」「指标」）+ 子项 `role="radio" aria-checked`**，不用 `aria-pressed`（那是 toggle，不是单选）。
- **roving tabindex**：只有选中项 `tabindex=0`，其余 `-1`；`←/→` 在组内移动并立即生效，`Tab` 离开整组。
- `seg()` 返回 `{ el, set(value) }`：**所有程序化改值必须走 `set()`**，由它同步 `aria-checked`、`tabindex`、视觉态，并派发 `segchange` 供外部订阅。禁止在别处直接改 `classList`——否则读屏读到的当前项与实际不符。
- `.seg` 的 `aria-label` 缺失视为缺陷，不接受"从上下文能看出来"。

**组标签两种形态**，按"选项本身有没有说清这是什么"选，不按"用得多不多"选：

| 形态 | 何时用 | 规格 |
|---|---|---|
| **行内前缀**（aria-only + 左侧灰字） | 工具栏里、垂直无余量；选项自解释（`60/120/250`、`不复权/前复权`、`MACD/KDJ/RSI`） | 组左侧 11px `--ink-3` 前缀（`区间`/`复权`/`指标`），**不占额外行高**；`aria-label` 仍需完整（"K 线区间"） |
| **可见标签**（组上方，aria 绑定） | 面板正文里、有垂直余量；选项是术语或缩写（`T0/T1/T2`、`20/60/120`） | 11px `--ink-3`，组上方 4px、左对齐、与组同宽不缩进；label 与组用 `aria-labelledby` 绑定 |

不可接受的两种：只给 `aria-label` 而视觉上完全无来源提示；给了可见标签却没和组绑定（读屏读成一段孤立文字）。

**选中态（定案，实现不许自选）**：选中 = **底部 2px `--accent` 下划线 + 文字 600 + `--ink`**；未选中 = `--ink-3`、无下划线。
- **不许再加方 / 点 / 勾 / 底色**——seg 是"模式切换"，不占形状预算（§4 七级顺位）。
- 下划线长度 = 文字宽 + 左右 4px，**不通栏**；通栏会看起来像 tab。
- 与 tablist 的分界：**seg 切参数（同一块内容换个口径），tab 换内容（另一块面板）**。下划线在项下 = seg，整块底下通栏 + 面板替换 = tab。

**本台 seg 清点（现存 3 组，应有 5 组）**

| 位置 | 组名 / aria-label | 选项 | 形态 |
|---|---|---|---|
| 个股 · 图上方 | K 线区间 | 60 / 120 / 250 | 行内前缀「区间」 |
| 个股 · 图上方 | 复权方式 | 不复权 / 前复权 | 行内前缀「复权」 |
| 个股 · 图上方 | K 线指标 | MACD / KDJ / RSI / 关 | 行内前缀「指标」 |
| 复盘 · 归因 | 归因窗口 | 20 / 60 / 120 日 | 可见标签 |
| 内核 · 数据信任 | 信任层 | 全部 / T0 / T1 / T2 | 可见标签 |

**三个不该用 seg 的地方**（写下来免得被"顺手统一"）：
- **今日 · 三池**（涨停/炸板/跌停）= **tablist**，它换的是内容面板，不是参数。
- **盘面 · 排序** = 点列头排序，不做 seg——`rank_by` 有 5 个值，塞进 seg 会挤掉表宽。
- **决策 · 票据状态筛选** = 下拉/多选 chips，9 个枚举值放不进 seg（且它是"筛掉一部分行"，不是"换口径"）。

### 7.3 图内标签与价格标签区（58px）
- 右侧价格标签区宽 **58px = 2px 色条 + 6px 间隙 + 50px 右对齐数字区**（11px mono 下 `123.45` 约 38px，留 12px 缓冲）。**只放价格**（含涨停 / 跌停 / 昨收）。**不放涨跌幅**：涨跌幅已在 sticky 顶栏常驻（12px），轴标签再放一遍属于同屏重复，违反 §6.3。方向靠色条（普通 `#8A93A3`，涨停/跌停时色条 +2px 高）。
- **涨停/跌停色条必须复用 `--px-up` / `--px-down`（`#FF5A63` / `#21C97C`）**，`--limit-up/--limit-down` 已删除。同一屏出现两种红，等于给"涨"两套说法。
- 例外：单个标签超 6 字符（三位数价格 `1234.56`）时整块切 `--kline-axis:64px`（plot 自动 −6px），**永不换行、永不省略号**（价格不能是 `12…`）。**切换粒度是整个标签区，不是单个标签**——同一轴上两列不同对齐比省略号更糟。
- clamp：`y = clamp(10, priceY, volTop − 10)`；`volTop` 之上 10px 为禁区，标签永不越入 VOL。**`VOL` 文字只出现在左轴**，右上角那格永远干净（净空从 8px 提到 10px）。
- 刻度 ≤6 个，含涨停 / 跌停 / 昨收；正负号用 U+2212 `−`，刻度数值不用缩写。
- **轴列锚点 = `main.x + main.w`，永不复用 `main.w`**。右侧附加列（价格标签、涨停/跌停线标注）一律按"主图右边界"定位；只要有一处写成绝对 `w`，`main.x` 一旦不为 0 就会整体错位，而当前几何下看不出错——这类 bug 只在别人改布局时显形。同理左侧轴用 `main.x`，不用 0。

### 7.4 读屏播报边界
- **判定零色相 → 必须有文字通道，而且要报"数"不只报"状态"。** `aria-label` 带可读原文：
  通过 → `"通过，34.94 低于闸门 38"`；不通过 → `"不通过，35.96 高于闸门 35"`；没有结论 → `"没有结论，情绪面板未生成"`（同一句也挂在缺数容器上，读屏一次拿全）；borderline 留空 → `"没有结论，无唯一答案：派生 34.94 对 38，厂商 35.96 对 35"`。
  **可见文字 ≤4 字**（`过` / `不过` / `未运行`），长句只走 aria——换行会让同一面板两行基线错开，扫读时会误以为换行处是新的一块。
- 三个数字读法：`pp` 写成**「个百分点」**（读屏会念成字母 P-P）；负号用 **U+2212 `−`**（不是连字符）；百分比与阈值之间加**「，阈值 」**，不写成 `34.94%/38%` 连读。
- **guard 矩阵整体**：`role="list"` + `aria-label="25 项前置检查，23 通过，1 阻断，1 未运行"`；20 格以上**不逐格 tab**，改方向键漫游（roving tabindex）。
- `aria-live="polite"` **只用于状态变化**：readiness 变了、熔断触发、票据状态变了、`gates.ok` 变了。价格与帧龄这类高频刷新**不播报**（会刷爆读屏）。
- **占比 / 比率数字必须能 hover 出「分子 / 分母」原文**：`100%` → `市值 5000.00 / equity 1.00`。
  这条不是给好奇的人看的，是**让"合法且完全错误"的数字无法隐藏**——分母是 1 的错会立刻暴露，而不是等某个人盯着 100% 觉得哪里不对。同类：任何除以净值的数字（仓位、单票、行业、现金、浮动盈亏）。
- 表格行要有 `aria-rowcount` 与「第 n 行，共 m 行」；`—` 单元格的可读文本是「未取到，<原因>」，不是「破折号」。
- 颜色不单独承载语义：涨跌/告警都必须同时有文字或形状（§4）。焦点环用 2px `#58A6FF` + 1px `#0B0D10` 内描边，深色底上 ≥3:1。
- `prefers-reduced-motion` 下禁用所有过渡（含抽屉滑入），保留即时显隐。

## 8 终验清单（对着过一遍，不读文案）

**A 数字有没有骗人**
1. 页面上搜不到裸数字：每个数值都能点出「哪个时刻 + 哪个来源」。
2. `/facts` 在盘中被标注为"昨日收盘"，不出现"实时"字样。
3. `null` 渲染成 `—`（虚框 + 原因 + 补数命令），`0` 渲染成干净 0；两者不会同时出现在同一处。
4. 同屏不存在两个来源的同名数字；跨面板引用带来源徽标。
5. 搜代码：没有 `Number(x) || 1`、`|| 0`、`value ?? 0` 这类兜底。

**B 状态说清楚没有**
6. 空列表能回答"为什么空"（用后端 `note` 原文，不自写）。
7. `gates.ok=null` 走灰虚框并折叠"今天做不做"结论区，不显示"不过"。
8. `borderline` 两行并列、判定位留空、差值不染色。
9. `tone_note` 两行等重、无图标、只有左 1px 灰线。
10. 500 是面板级红紫框，不遮全页；401 是浮层遮蔽，恢复后不重放 POST。
11. `omitted_sections` 有"缺 N 块，点此单独取"的入口。

**C 形状有没有撞车**
12. 判定只有三态：空心方 / 实心方 / 空位+原因；无虚线方、无点线方。
13. 可见判定文字 ≤4 字；`aria` 报数。
14. 涨停/跌停是文字 chip，不是方块；全站只有一对红绿。
15. 危险按钮不染色，点击原地变"再点一次确认（3 秒）"，3 秒回退。
16. 全屏只有一个实心按钮；熔断是紫圆点不是方块。

**D 能不能用键盘走完三条流**
17. 09:26 全流程不摸鼠标：`g1` → `j/k` 选候选 → `Enter` 进个股 → `p` 提案 → `a` 审批（弹层）。
18. 弹层：Esc = 取消且 resolve false；焦点进得去、困得住、出得来；背景不滚。
19. `j/k` 在 20 行以上列表仍跟手；`Enter` 不会误触成交。

**E 密度站不站得住**
20. 1440×900 首屏不滚动能看到该页全部 `[首]` 面板。
21. 表格行高 24、字号 12–13，单屏 ≥14 行；无横向滚动条。
