# quant-desk playbook · 草案 §9.7（门后不得追加否决）

> 本草案只加一条执行纪律。**不放宽任何硬门**：§9.3 的两条通过条件一个字不改，§2 的仓位、§8 的跳空门、成本与止损全部不动。它与未激活的 `pb-20261109193448-6fb8c7`（§9.6 赔率门拆三值）相互独立、不互相替代，两份都需要人工激活。

## 9.7 赔率门之后不允许追加否决（2026-11-10 加）

**9.7.1 门的边界**

§9.3② 的赔率门只有两条通过条件，且是**或**关系：

1. 5 日 `excess_ci95` 下沿 > 91.93bps（往返成本）；
2. `quant_analog` n ≥ 1 且 `distance_band != far`。

满足其中任意一条即为**通过**。通过之后，报告与提案不得再用下列任一项否决该票：

- 「5 日 `excess_day_mean` 为负」或「扣成本后净超额为负」；
- 「5 日绝对收益均值/中位数为负」；
- §0「单笔目标收益 ≥ 2%」；
- §4 checklist 第 3 条「赔率 ≥ 2」。

这四项是**仓位与目标**的要求（买多少、目标多少、失效条件写什么），不是门的组成部分。把同一个负的历史均值同时用作「门」和「仓位」，等于给同一只票两次否决权。

**9.7.2 通过之后该做什么**

按顺序三件事，不许跳：

1. 定尺寸：1 手为起点，一手金额 ≤ 25% 权益（5,000 元账户 = 1,250 元）；
2. 定容量：单只 ≤ §2 的 30%，`max_positions=3`、`min_cash_weight=0.2` 照旧；
3. 定失效：`invalidation` 必须可验证（价格/时间/数据三选一），止损由服务端算。

每日经此路径的开仓最多 **1 只**（与 §9.6 的试仓名额共用，不叠加）。若当日通过门的票一手金额 > 1,250 元 → 该票不可买，写明「整手约束」而不是「赔率不够」。

**9.7.3 仍然可以否决的**

- `excess_ci95` **整段为负**（有证据的跑输）；
- `distance_band = far` **且** `analog` n < 1（没有任何历史样本，等于不知道，只能不买）；
- 跳空门 `x ≤ −2%`、`x > 3%`（§8）；
- 组合层风控（`max_positions`、`min_cash_weight`、`max_aggressive_weight`、日亏与回撤闸）。

**9.7.4 验收与作废**

- 样本闸：3 个交易日内（自激活日或本条被执行的第一个交易日起算）至少 **1 笔**走「过门即进仓位」路径的提案。3 日 0 笔 → 本条作废，回退到「允许在门后追加赔率否决」，并在复盘写明当时真正挡路的是哪一条。
- 质量闸：该路径的平仓笔数到 n ≥ 5 后，若 `mean_excess < −0.92%` → 作废。
- 与 §9.6 共用名额时，先记 `declined` 或 `thesis` 里写明走的是哪一条路径，否则事后无法归因。

## 变更理由（给激活的人）

- 来源：2026-11-10 19:30 收盘对账（`reports/review/20261110.md`）。
- 触发：当日 10 只过首窗赔率门的候选里，报告自认「第二分支有 3 只过：002354、300432、300315」，随后以「过了几何门不等于有赔率」全部否决。三只当日等权 open→close **+3.11%**、对等权市场 **+1.34pp**（002354 +2.39pp、300315 +2.19pp、300432 −0.57pp）。18 天 `arena.edge.n=0` 里，至少这一笔是「门已开、手没动」。
- 同一天赔率门整体 2 对 8 错，被否的 10 只等权 **+3.70%**、对市场 **+1.92pp**——两个数指向同一件事：门后的那层判断，是当日最大的漏损点。
- 风险：这是把「已通过的票必须进仓位计算」写成硬约束，可能增加低质量成交。缓解：尺寸固定 1 手、每日 1 只、验收设 3 日 0 笔与 n≥5 均值双作废。样本没到之前只给方向，不允许据此声称有 edge。
