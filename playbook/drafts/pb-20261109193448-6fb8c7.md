# quant-desk playbook · 草案 §9.6 与 §8.2 修订

> 本草案只改两处：赔率门的「无证据」处理（新增 §9.6）与放行路的仓位口径（重写 §8.2）。其余条款、所有仓位上限、成本、止损、风控一律不动。

## 9.6 赔率门分两档：「无证据」不等于「证据为负」（2026-11-09 加）

**9.6.1 两种否决要分开**

赔率门的输出从二值（过 / 不过）改为三值：

| 状态 | 触发条件 | 处置 |
|---|---|---|
| `evidence_negative` | 5 日 `excess_ci95` **整段为负**；或 `survives_cost=false` 且 `net_excess < −1%` | **否决**，不进试仓 |
| `no_evidence` | `distance_band=far`；或 `excess_ci95` **跨 0**；或 `analog` n<1 | **允许试仓**（口径见 9.6.2），不得据此否决 |
| `evidence_positive` | `excess_ci95` 下沿 > 91.93bps | 正仓（按 §2 与 `max_aggressive_single` 执行） |

**理由**：红线 4 的原文是「`quality=loose` 就当没查到」——「没查到」是一个信息状态，不是一个负向信号。2026-11-09 实测 8 只 `distance_band=far` 的标的 6 赢 2 输、当天均值 +2.26%、对等权超额 +2.15pp（002724 +7.66pp、300006 +7.51pp、000700 +2.41pp 均被 `far` 否掉后跑赢）。把「我不知道」当成「它会跌」，结果是 17 个交易日 `arena.edge.n=0`、永远拿不到一份可结算的样本。

**9.6.2 试仓口径（硬参数）**

- 尺寸：**1 手**（不是权重），金额 ≤ **25% 权益**（5,000 元账户 = 1,250 元）。
- 频度：**每日最多 1 只**，只允许在 09:26 或 14:35 各一次。
- 不得加仓：试仓当日不得再买同一只，也不得因为试仓而突破 `max_positions=3`。
- 止损照旧由服务端算，T+1 照旧生效。
- 若 1 手金额 > 25% 权益 → 该标的不可买（整手约束，不是试仓失败）。

**9.6.3 记账要求**

试仓必须写 `quant_declined`（若最终未买）或在 `thesis` 里写「本票走 §9.6 试仓路」，否则事后无法区分「试仓」与「正仓」，验收也就无法做。

**9.6.4 作废条件**

1. 样本闸：记为试仓路径的平仓笔数 **n ≥ 10** 后，若 `quant_declined.result.mean_excess < −0.92%`（往返成本）或 `quant_arena.edge.ci_high < 0` → 回退为「无证据即否决」。
2. 时间闸：**3 个交易日（20261110 / 20261111 / 20261112）内该路径仍 0 笔尝试** → 本条不是瓶颈，在复盘里写明当日真正挡路的是哪一条（闸门 / 跳空门 / 整手），并停用试仓权，不再顺延。
3. 单日风控照旧：`daily_loss_no_new` / `drawdown_half` / `kill_switch` 优先于本条。

## 8.2 放行路的限额（重写）

原文「单只仓位 ≤ 10%」在 5,000 元账户上等于 **500 元**，而任何 ≥5.00 元的票一手即 ≥500 元：2026-11-09 三只放行路（300133 一手 1,010 元、002181 1,113 元、002696 1,157 元）全部出局，若买均值 +1.21%（市场 +0.11%）。

改为：

- `−2%~0` 档每日最多放行 **1 只**；
- 尺寸口径从权重改为**整手**：`1 手`，且一手金额 ≤ **25% 权益**（与 §9.6.2 同一口径，不再另设一个数）；
- 放行的票必须在 `open(D)` 写明「本票走 §8.2 放行路」，并在 `declined` 记入（若最终未买）。

**为什么用整手而不是权重**：5,000 元账户上，25% = 1,250 元 与 10% = 500 元之间的差别不是「保守」与「激进」，而是「买得到」与「买不到」。1 手是交易所的最小单位，权重必须服从它。

## 8.7 试仓与放行路的关系

§8.2 与 §9.6 是**两个入口、同一口径**：跳空门放行的票仍要过赔率门；过了赔率门而只拿到 `no_evidence` 的，进试仓（1 手 / ≤25% / 每日 1 只）。两个入口共用那一个「每日 1 只」的名额，不叠加。
